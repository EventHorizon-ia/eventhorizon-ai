## 🚀 Sobre Mim

Olá! Sou o **Lucas Theodoro**, desenvolvedor focado em Machine Learning de Alta Performance, Engenharia de Dados e Soluções Predictivas de mercado. Unindo uma mentalidade hacker a uma visão empreendedora, busco transformar arquiteturas de IA complexas em valor real ponta a ponta.

* 🧠 **Founder na EventHorizon-AI:** Plataforma de inteligência artificial voltada a dados e previsões temporais complexas.
* 📈 **Validação Prática:** Desenvolvi engines robustas de previsão estruturadas com arquiteturas híbridas de **Transformer + BiLSTM** para mercado cripto e **LightGBM** escalável para previsão de demandas de mercado.
* 📦 **Open-Source:** Autor e mantenedor da biblioteca pública no PyPI: [`honest-validation-toolkit`](https://pypi.org/project/honest-validation-toolkit/).
